# IBAMR Output Files Documentation

## Overview

This directory contains detailed documentation for **each type of output file** generated by IBAMR simulations with immersed swimming bodies.

Each file has comprehensive information including:
- File format and column structure
- Physical interpretation
- Data analysis examples with Python code
- Troubleshooting guide
- Input file configuration

## Quick Navigation

### Control Volume (CV) Force Files

| File | Description | Key Use |
|------|-------------|---------|

## File Naming Conventions

### Control Volume Files

```
Pattern: Drag_CV_strct_id_N
         Torque_CV_strct_id_N

Examples:
  Drag_CV_strct_id_0     - Force on structure 0
  Drag_CV_strct_id_1     - Force on structure 1
  Torque_CV_strct_id_0   - Torque on structure 0
```

### Structure Files

```
Pattern: <basename>_<quantity>_struct_no_N
         <basename>_<quantity>_struct_no_N.curve

Examples:
  Eel2d_COM_coordinates_struct_no_0
  Eel2d_Trans_vel_struct_no_0
  Eel2d_Drag_force_struct_no_0.curve
  Foil_Power_spent_struct_no_1
```

Where:
- `<basename>`: From input file (e.g., "Eel2d", "Foil")
- `N`: Structure ID number (0, 1, 2, ...)

## Common Analysis Tasks

### 1. Measure Thrust (Tethered Swimming)

**Files needed:**
- [Drag_CV_strct_id.md](./Drag_CV_strct_id.md)

```python
import numpy as np
data = np.loadtxt('Drag_CV_strct_id_0')
time = data[:, 0]
Fx = data[:, 1]  # Negative = thrust

# Mean thrust
mask = time > 5.0  # Skip transient
thrust = -np.mean(Fx[mask])
print(f"Mean thrust: {thrust:.6f} N")
```

### 2. Compute Swimming Speed (Free Swimming)

**Files needed:**
- [Trans_vel_struct.md](./Trans_vel_struct.md)

```python
data = np.loadtxt('Eel2d_Trans_vel_struct_no_0')
time = data[:, 0]
Vx = data[:, 1]

mask = time > 5.0
V_steady = np.mean(Vx[mask])
print(f"Steady speed: {V_steady:.6f} m/s")
```

### 3. Calculate Propulsive Efficiency

**Files needed:**
- [Drag_CV_strct_id.md](./Drag_CV_strct_id.md)
- [Power_spent_struct.md](./Power_spent_struct.md)

```python
force_data = np.loadtxt('Drag_CV_strct_id_0')
power_data = np.loadtxt('Eel2d_Power_spent_struct_no_0')

Fx = force_data[:, 1]
P_input = power_data[:, 3]

U_inf = 1.0  # m/s
P_output = -Fx * U_inf

mask = time > 5.0
eta = np.mean(P_output[mask]) / np.mean(P_input[mask])
print(f"Efficiency: {eta:.4f} ({eta*100:.2f}%)")
```

### 4. Track Body Trajectory

**Files needed:**
- [COM_coordinates.md](./COM_coordinates.md)

```python
data = np.loadtxt('Eel2d_COM_coordinates_struct_no_0')
X = data[:, 1]
Y = data[:, 2]

import matplotlib.pyplot as plt
plt.plot(X, Y)
plt.xlabel('X (m)')
plt.ylabel('Y (m)')
plt.title('Swimming Trajectory')
plt.axis('equal')
plt.show()
```

### 5. Analyze Turning Maneuvers

**Files needed:**
- [Rot_vel_struct.md](./Rot_vel_struct.md)
- [Torque_CV_strct_id.md](./Torque_CV_strct_id.md)

```python
vel_data = np.loadtxt('Eel2d_Rot_vel_struct_no_0')
omega_z = vel_data[:, 3]  # Angular velocity

# Detect turns
turning = np.abs(omega_z) > 0.1  # rad/s threshold
print(f"Turning {np.sum(turning)} timesteps")
```

### 6. Validate Force Calculations

**Files needed:**
- [Drag_CV_strct_id.md](./Drag_CV_strct_id.md)
- [Drag_force_struct.md](./Drag_force_struct.md)

```python
cv_data = np.loadtxt('Drag_CV_strct_id_0')
struct_data = np.loadtxt('Eel2d_Drag_force_struct_no_0.curve')

Fx_cv = cv_data[:, 1]
Fx_struct = struct_data[:, 1]

# Compare
error = np.mean(np.abs(Fx_cv - Fx_struct))
print(f"Mean difference: {error:.6e} N")
```

## File Dependencies

### Fundamental Files (Always Generated)

1. **Drag_CV_strct_id_N** - Forces
2. **COM_coordinates** - Position

### Conditional Files (Based on Input Settings)

Enabled in `PrintOutput` block:

```
ConstraintIBMethod {
    PrintOutput {
        output_drag = TRUE              → Drag_force_struct
        output_torque = TRUE            → Torque_struct
        output_power = TRUE             → Power_spent_struct
        output_rig_transvel = TRUE      → Trans_vel_struct
        output_rig_rotvel = TRUE        → Rot_vel_struct
        output_com_coords = TRUE        → COM_coordinates
        output_moment_inertia = TRUE    → MOI_struct
        output_eulerian_mom = TRUE      → EULERIAN_MOMENTUM
    }
}
```

## Configuration: Free Swimming vs Tethered

### Free Swimming (Body Can Move)

```
ConstraintIBKinematics {
    calculate_translational_momentum = 1,1,0
    calculate_rotational_momentum    = 0,0,1
}
```

**Expected behavior:**
- `Trans_vel_struct`: Non-zero (increases with time)
- `COM_coordinates`: Changes (body moves)
- `Drag_CV`: Approaches zero at steady state
- `Rot_vel_struct`: Non-zero for turning

### Tethered (Fixed Position)

```
ConstraintIBKinematics {
    calculate_translational_momentum = 0,0,0
    calculate_rotational_momentum    = 0,0,0
}
```

**Expected behavior:**
- `Trans_vel_struct`: All zeros
- `COM_coordinates`: Constant
- `Drag_CV`: Net thrust (negative Fx)
- `Rot_vel_struct`: All zeros

## Data Format

### All Files Use Tab-Separated Values (TSV)

```
# Column 1: time (s)
# Column 2: ...
# Column 3: ...
```

### Reading in Python

```python
import numpy as np
data = np.loadtxt('filename')
time = data[:, 0]
column2 = data[:, 1]
```

## Troubleshooting

### Problem: File not created

**Check:**
1. Output flag enabled in input file
2. Structure registered properly
3. Output directory exists and writable

### Problem: All values are zero

**Check:**
1. Simulation has run (check time column)
2. Swimming kinematics defined
3. Boundary conditions set

### Problem: Values seem wrong

**Verify:**
1. Units (dimensional vs non-dimensional)
2. Sign conventions
3. Steady state reached (skip transient)
